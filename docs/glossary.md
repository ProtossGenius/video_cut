# VideoCut - 术语表 (Glossary)

本文档包含了 VideoCut 项目中使用的所有核心专业术语的中英文对照及其在本项目中的具体含义解释。

## 核心编辑术语

| 英文术语 | 中文翻译 | 描述 |
|---|---|---|
| **Timeline** | 时间线 | 用来布置、组织和查看视频/音频切片的全局视图与时间轴面板。 |
| **Track** | 轨道 | 时间线中的一条水平载体，用于承载多段媒体切片。视频轨道越靠上，Z 轴显示越靠前。 |
| **Clip** | 切片 | 轨道上的一段连续的媒体片段，是剪辑的最基本元素。对应一份视频、音频或图片。 |
| **Anchor** | 锚点 | 时间线上的标记点（Marker）。可以挂载在轨道全局，也可以绑定在切片局部，便于快速跳转。 |
| **Keyframe** | 关键帧 | 定义动画、特效或变换在特定时间点的属性值的控制点。 |
| **NLE** | 非线性编辑 | Non-Linear Editing。区别于传统磁带剪辑，可以随意跳转时间线、不按顺序修改视频的一种剪辑方式。 |
| **Trash Track** | 垃圾轨道 | 项目界面最底部的一条特殊轨道，用于存放刚刚被删除的切片（回收站机制），支持粘贴恢复。 |
| **Pin** | 置顶 | 将特定的轨道固定在时间线视图的顶部，不随轨道滚动条上下滚动。 |

## 技术与架构术语

| 英文术语 | 中文翻译 | 描述 |
|---|---|---|
| **Modal** | 模态 | vim 风格的输入模式（例如 Normal 正常模式 / Visual 视觉选择模式 / Command 命令模式等）。 |
| **Trie** | 前缀树 | 字典树。在本项目中用于高效存储和解析 vim-like 的按键组合序列（如 `v5l` 或 `ma`）。 |
| **Rope** | Rope 数据结构 | 一种由二叉树/B-Tree 实现的数据结构，用于极速处理超大文本的插入与删除操作。内置 Lua 编辑器依赖该结构。 |
| **YUV** | YUV 颜色空间 | 视频压缩中最常用的色彩编码格式。本项目利用 GPU shader 将 YUV 转换为 RGB。 |
| **PCM** | 脉冲编码调制 | Pulse Code Modulation。未经压缩的数字音频原始数据格式。 |
| **LRU** | 最近最少使用 | Least Recently Used。一种缓存淘汰算法，用于管理已解码的视频帧缓存，防止内存溢出。 |
| **LOD** | 多分辨率细节级别 | Level of Detail。在波形图中，生成 1:100, 1:1000, 1:10000 比例的波形顶点以实现无卡顿缩放。 |
| **Sandbox** | 沙箱 | 为用户 Lua 脚本执行提供的隔离和安全环境，防止恶意操作文件系统或造成死循环。 |
| **WAL** | 预写日志 | Write-Ahead Log。自动保存机制之一，在修改主项目文件前先将编辑命令写入日志，防止崩溃丢失数据。 |
| **DAG** | 有向无环图 | Directed Acyclic Graph。用于描述音视频特效渲染管线的节点和依赖关系。 |
| **SPSC** | 单生产者单消费者 | Single-Producer Single-Consumer。一种多线程并发模型，本项目音频渲染使用 SPSC Ring Buffer。 |
| **ECS** | 实体组件系统 | Entity Component System。一种数据驱动架构模式，本项目结合了类似 ECS 的注册机制来管理特效和属性。 |
| **Waveform** | 波形图 | 音频波动的可视化表示，绘制在轨道切片的下半部分。 |
| **I-frame** | 关键帧（内编码帧） | Intra-frame。视频压缩中的完整参考帧。进行视频定位（Seek）时，解码器必须先跳到此帧。 |
| **Bisect** | 二分选择 | visual 状态下的一种二分法选择机制，在画面两边显示蒙版，按 `=-` 选择左右半段来精确裁切。 |
| **Playhead** | 播放头/光标 | 时间线上指示当前预览播放位置的游标指针。 |
