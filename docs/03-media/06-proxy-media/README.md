# 虚拟代理剪辑流与低分辨率下采样缓存生成器 (Proxy Media Pipeline & Offline Editing)

针对 4K/8K、高帧率与高码率素材在密集剪辑、多轨道叠加与快速穿梭时的卡顿问题，提供轻量级代理媒体（Proxy Media）管线。在预览剪辑时读取下采样代理文件，导出时自动无缝回退至超清原始素材。

## 代理分辨率预设 (`ProxyResolution`)
- `Low720p`：标准高清代理 (1280x720，流畅度与清晰度平衡)
- `Low360p`：极速粗剪代理 (640x360，超低内存开销，极致流畅)
- `Half`：原始分辨率 1/2 等比缩放 (例如 4K 缩放至 1080p)
- `Quarter`：原始分辨率 1/4 等比缩放

## 实时下采样与无缝切源 (`ProxyManager`)
- **像素下采样算法**：支持快速步进抽取与双线性面积平均下采样，生成低延迟紧凑帧缓存。
- **无缝动态切换**：通过全局状态一键切换 `PROXY: ON/OFF`，播放器解码器根据代理启用状态动态分发视频帧。

## 交互命令与快捷操作
- **状态栏切换**：状态栏常驻 `⚡ PROXY: ON/OFF` 徽标按钮，支持鼠标一键切换。
- **右键上下文菜单**：切片右键菜单提供 `⚡ 生成代理媒体` 与 `⚡ 切换代理/原画`。
- **命令行**：
  - `:proxy [on|off|toggle]`：全局开启/关闭/切换代理媒体预览。
  - `:gen_proxy [720p|360p|half|quarter]`：为当前切片或选区素材生成下采样代理。
  - `:proxy_status`：查看当前工程所有素材的代理就绪状态。
