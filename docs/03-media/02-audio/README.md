# 音频处理与主时钟

音频在剪辑软件中不仅是发声源，更是**整个系统的物理时钟**。

## 音频管线
1. **设备通信**：使用 `cpal` (v0.18.1) 初始化操作系统的默认音频输出设备。
2. **解码**：使用纯 Rust 的 `symphonia` (v0.6.0) 解码 MP3/WAV/FLAC/AAC 等数据。
3. **重采样**：因为不同素材采样率不一，必须统一使用 `rubato` (v5.0.0) 的 Sinc 重采样器将所有切片的音频拉齐到输出设备的标准采样率（例如 48000 Hz）。
4. **锁无关传输**：使用 `rtrb` 创建 Lock-free 的 SPSC（单生产者单消费者）Ring Buffer。Timeline 线程作为 Producer 混音后推入缓存，`cpal` 实时回调线程作为 Consumer 拉取采样。

## 音频主时钟原则
绝对不允许将视频帧率（如 60FPS 的 egui 循环）作为时间准星。
系统当前准确时间 = `已消耗的音频采样点总数 / 输出采样率`。视频引擎每一帧渲染时向此时间对齐。

## 主音量控制与 VU 电平表 (Master Volume & VU Meters)
- **音量增益调节**：支持 `:vol <0.0~2.0>` (如 `:vol 1.2` 提升至 120%)、`:mute` 静音与 `:unmute` 取消静音。
- **立体声 VU 电平表**：在界面实时展示左右声道 RMS 与 Peak 峰值电平，具备平滑物理衰减动画与 >0dB 红色削顶警示。
