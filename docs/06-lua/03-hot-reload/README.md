# 热重载机制

极大地提升开发体验，不需要反复重启应用来看特效代码的更改效果。

基于 `notify` (v8.0.0) 的文件系统监听机制。

1. 系统后台持有一个 `RecommendedWatcher`，监听当前项目下引用的所有 `.lua` 文件所在的文件夹。
2. 捕获到 `EventKind::Modify` 后。
3. 主线程发起重载请求，清空特定空间的缓存执行 `lua.load(&new_script).exec()`。
4. 如果 Lua 解析发生了 syntax error，**捕获错误并使用 egui 的 Toast 弹窗或在状态栏显示红字警告**，同时老版代码依然维持在内存中继续运行，保证播放不因崩溃中断。
