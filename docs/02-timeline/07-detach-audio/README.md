# 视频音画分离与独立音频轨道派生 (Audio-Video Separation & Detach Audio Track Engine)

支持将视频切片（包含视频与伴音流）一键分离为独立的纯视频切片和派生出的纯音频切片。

## 分离机制
1. **自动查找或创建音频伴音轨 (Audio Track)**：
   - 检查时间线上是否存在对应的音频轨道（以 `A` 开头，例如 `A1` 或 `Audio`）。若无则自动在下方插入新的音频轨道。
2. **派生独立音频切片**：
   - 创建新切片，命名为 `[音频] {原切片名}`，继承原切片的 `source` 资源、`source_in`、`source_out` 与 `timeline_start`。
   - 原切片标记或转换为纯视频轨道切片。
3. **音画时间对齐与联动**：
   - 分离后的音频切片与原视频切片在时间线上保持严格一致的起止位置与淡入淡出曲线。

## 交互命令与上下文菜单
- `:detach_audio` 或 `:split_av`：将当前切片的伴音抽取分离至音频轨道。
- 切片右键上下文菜单提供 `🔊 音画分离至新音频轨 (:detach_audio)` 操作项。
