# 磁性时间线吸附与智能对齐标尺 (Magnetic Timeline Snapping & Smart Guides)

在时间线上移动播放指针（Playhead）或拖拽切片边界时，磁性吸附引擎会自动将当前时间点吸附至邻近的关键对齐点。

## 吸附目标点 (Snap Targets)
1. **切片边缘点 (Clip In/Out Points)**：当前轨道及所有其他轨道上切片的起始与终止时间。
2. **全局锚点 (Global Anchors)**：项目全局注册的锚点标记位置。
3. **局部锚点 (Local Anchors)**：当前切片及邻近切片上的命名锚点。
4. **播放指针当前位置 (Playhead)**：切片拖拽时向当前播放指针位置吸附。

## 磁性吸附算法与阈值
- 吸附阈值默认：屏幕像素距离 `8.0px`（对应时间 `FrameTime = (8.0 / zoom_level) * 1_000_000`）。
- 当吸附命中时，在时间线所有轨道上方绘制纵向橙黄色贯穿吸附标尺辅助虚线（Smart Guide Line），并在状态栏/顶部标尺处提示吸附目标（例如 `🧲 对齐至: [Clip "intro.mp4" 终止点]`）。

## 交互命令与快捷切换
- `:snap [on|off]` 或 `:toggle_snap`：开启/关闭磁性吸附开关。
- 快捷键 `S` 或 `Shift+S`：在时间线视图中快速切换磁性吸附状态。
- 在状态栏右侧展示 `🧲 SNAP: ON` 状态徽标。
