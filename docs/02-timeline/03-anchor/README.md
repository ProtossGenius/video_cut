# 锚点系统 (Anchor/Marker)

用于在时间线上打上书签或定位符。

## 操作流
### 设置锚点
- `m <字母/数字>`：创建一个**局部锚点**。作用域仅限当前切片（移动切片时锚点跟着移动）。
- `M <字母/数字>`：创建一个**全局锚点**。作用域是整条轨道（绝对时间点）。
- `m:`：开始输入长名称锚点，直到按下 `Enter` 结束。输入期间在状态栏回显字符。
- *如有重名锚点，则直接覆盖原位置。*

### 跳转与搜索
- 按下单引号 `'` 触发跳转模式，随之弹出帮助面板。
- 帮助面板的最上方固定展示 `单引号`（用于匹配多字母）和 `冒号`。
- 其他条目列出可用的单字母/数字锚点，右侧附带该时间点的**视频截图**和**描述**。
- 若按下的是长名称锚点前缀，帮助面板变为**单列多行**布局，使用拼音及模糊匹配高亮显示过滤结果，`Alt+j/k` 选择，`Enter` 跳转。

### 视图查看
- `:Marks` 命令：展示所有锚点列表的管理面板，可以在此编辑锚点描述（Description）。
