# 选择系统 (Selection)

VideoCut 将选择模式分为“对象级选择”和“范围级选择”。

## `V` (大写) 模式：对象级切片选择
- 进入此模式后，可以通过 `h`/`l` 在同一轨道内多选切片。
- 支持前缀计数器，如 `v 5 l` 等价于按 5 次右移选择。

## `v` (小写) 模式：时间范围选择
- 以时间游标为核心的拖拽选择。
- `h`/`l` (或 `+`/`-`, `_`/`=`)：默认以 `1s` 为步进间隔向左右扩展选中范围。
- 支持直接跨越多个切片。
- 支持配合跳转键：按 `w` 直接选中到下一处声音，或者按 `'a` 选中到锚点 a 的位置。
- 支持按空格键在播放过程中“拉出”选择区域。

## 确认与后续操作
- `Esc`：取消选择，退回 Normal 模式。
- `Enter`：确认选中该范围，状态固定为 **Visual 状态**。之后 Lua 脚本绑定的作用于 `visual` 模式的命令方可执行。

## `:biset` 二进制选择 (Visual专属)
一种极速寻找画面的操作。
1. 在选中的长切片范围内调用 `:biset`。
2. 画面进入放大模式。两端出现彩色半透明蒙版，分别标记为 `-`（左半）和 `=`（右半）。
3. 用户按键后，放弃的一半画面平滑移出屏幕，保留的一半再次居中放大分半。
4. `Backspace` 可以撤销上一次的二分决定。
5. `Enter` 确认切割点，`Esc` 取消。
