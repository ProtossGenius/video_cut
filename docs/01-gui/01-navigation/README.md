# 导航页面

应用启动时的初始页面，用于项目的选择与管理。

## 页面结构
- 使用 `egui::CentralPanel` + `egui::ScrollArea` 构建网格视图。
- 每一个项目由**视频缩略图**（左侧/上方）和**名称**组成。
- 首个项目固定为 `+ 新建项目`。

## 交互设计
- `f`：启动 Quick-Select（类似 Vimium 的 f 键），在每个项目图标上悬浮字母，按下对应字母即可打开项目。
- `j`/`k` 或方向键：上下/左右移动光标。
- `Enter`：打开当前选中的项目。
- `D`：删除项目（实际上是将其移动到系统的 `/tmp/videocut_trash/` 目录下）。
- `Y`：复制选中项目。
- `P`：粘贴（支持恢复刚刚删除的项目）。
- `/`：触发搜索状态。

## 搜索功能 (Search)
- 按下 `/` 后，在左下角展示用户输入的字母序列。
- 结合 `pinyin` 库将中文项目名转换成拼音。
- 使用 `nucleo` 提供模糊匹配排序。
- 在缩略图的名称中，将匹配的部分**高亮显示**。匹配度越高的排在越前面。

## 缩略图实现
- 后台使用 `ffmpeg-next` 抓取视频的第一帧。
- 使用 `fast_image_resize` 缩放至统一大小的略缩图，通过 `egui-wgpu` 加载为 `TextureHandle` 供 UI 绘制。
