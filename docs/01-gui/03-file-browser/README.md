# 文件导入页面

悬浮式的文件管理器。

## 页面结构（三列布局）
- 左侧：上一层（父文件夹）内容预览。
- 中间：当前文件夹的文件列表（焦点区域）。
- 右侧：选中文件的预览视口（若是文件则为帧截图，若是文件夹则为子级文件列表）。

## 操作逻辑
- 弹出此页面是一个独立悬浮窗口 `egui::Window`。
- `X` 或 `Esc`：关闭窗口取消导入。
- `j`/`k`：上下移动选择。
- `Enter`：
  - 如果是文件：确认选中/导入。
  - 如果是文件夹：进入该文件夹。
- `Shift+Enter`：强制选中当前文件夹本身。
- `Backspace`：返回上一级目录。
- `y`：复制包含文件名的完整路径。
- `Y`：复制当前所在路径的父目录。

## 导出与重命名逻辑
- 按英文 `:` 或中文 `：` 编辑导出名称。
- `Shift+Enter` 触发导出动作。
- 若文件重名且扩展名相同，弹出提示（`R` 覆盖 / `C` 另存为 / `Q` 取消）。

## 技术实现
- 基于 `walkdir` 遍历目录，为了避免阻塞 UI 线程，需要在后台线程并行扫目录，然后传给主线程。
- 对于选中视频的右侧预览，按需派发异步任务让 `ffmpeg-next` 取第一帧并传回纹理 ID。
