# 内部编辑器界面

用于编写自定义特效与参数脚本的 Lua 编辑环境。

## 页面结构
- 左侧：纯键盘驱动的文本编辑器（Vim-like 代码视图）。
- 右侧上半：视频预览界面（同步展示脚本修改效果）。
- 右侧下半：当前切片所在时间线轨道的局部只读视图。

## 编辑器约束与能力
- 此模式下，**轨道区是只读的**，禁止编辑轨道，只能预览。
- `Alt + h/l`：在左右视窗间切换焦点。
- 编辑器的操作模式标识为 `editor`。
- 支持 `Lua` 的语法高亮（基于 `tree-sitter-lua`）。
- 支持 API 自动补全功能（集成 `mlua` 中暴漏给 Lua 的运行时 Rust API）。

## 技术实现
- 编辑器并非一个简单的 TextInput，由于需要语法高亮和光标管理，必须在后端使用 `ropey` 管理多行文本结构。
- 每次按键编辑提交到 `tree-sitter` 执行增量解析，再根据节点类型对 `egui::text::LayoutJob` 进行分段着色。
