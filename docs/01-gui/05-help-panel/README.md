# 帮助面板

用于在全键盘操作中随时提供快捷键提示的交互系统。

## 触发机制
- 在任何支持快捷键的焦点区域按下 `?`，帮助面板将在底部状态栏的上方悬浮出现。

## 布局设计
- 面板呈现为**多行多列**。
- 首行居中显示标题，如“时间线组件帮助列表”。
- 数据项格式：`[按键/字母]` - `[描述文本]`。
- **分组展示**：如果有一系列快捷键拥有共同的前缀（如 `ad` 绑定在 Lua `main:bind_group_desc('ad', 'add sth.')`），则默认显示前缀字母和描述并在后面加 `...`。当用户按下前缀后，只显示该前缀下的详细快捷键。

## 技术实现
- 通过拦截 `egui::Event::Key` 进行状态判断。
- 面板使用 `egui::Area` 以悬浮模式挂载，Z-index 置于最高。
