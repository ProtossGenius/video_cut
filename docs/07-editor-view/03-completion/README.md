# 代码补全

编辑器需要知道系统里开放了哪些组件 API 才能达到生产力标准。

- **分析阶段**：获取正在输入的标识符前缀（基于 Tree-sitter 的光标位置节点查询）。
- **静态词库与全局注入**：利用 `mlua` 提供的方法内省机制，把全局 `globals` 挂载表中的键名全部动态导出作为一个动态词典库。
- 将动态获取到的内建函数名（如 `bind_key`, `focuse`, `rect`, `moveto` 等）投喂到补全引擎。通过弹窗选择即可。
- **Follow 目标补全**：编辑器会从当前工程的时间线实时提取 `轨道名.切片名` 目标路径，同时提供裸标识符与单引号/双引号字符串形式补全，便于直接输入 `follow('V1.Intro')` 这类引用。
- **字符串上下文识别**：当光标位于未闭合的 `'...'` / `"..."` 字符串字面量中时，补全前缀提取器会保留空格与点号，从而支持如 `'Track 1.video1.mp4'` 这样的路径补全。
