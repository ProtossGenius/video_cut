# 自动保存与防丢机制

视频剪辑极容易受内存溢出或者机器断电干扰，必须做好最坏情况防护。

## WAL 命令日志 (Write-Ahead Log)
不需要每做一次裁剪就把几兆大小的完整 JSON 序列化刷写磁盘（会卡顿）。
所有的修改必然是一个 `Command`。项目目录存放一个基于附加写的 `.wal` 文件。每生成一个 Command，将其动作日志迅速 append 写入进去并 flush。
当发生断电重启时，系统先读取最后的 `.vcut`，然后依次解析 `.wal` 里的日志流按顺序回放播放到崩溃前的一瞬，实现数据完美重现。

## 安全原子覆盖
在需要对 `.vcut` 全量存档时（如手动保存，或退出程序时）：
先写入一个带随机数后缀的临时文件（如 `.vcut.temp`），等完全落盘且操作系统刷完内核缓存后，再使用原子级的 `fs::rename` 覆盖掉真实的 `.vcut` 文件。确保中途出意外不会留下一个格式损坏了一半的工程文件。
