# 项目文件格式

统一扩展名为 `.vcut`。
它实际上是一个具有严格结构体标注（Schema）的纯 `JSON` 格式文本文件，经由 `serde_json` 转换。

## 选择 JSON 的理由
1. 对版本控制极为友好（可以配合 git 做项目的多人增量协作和 diff 追溯）。
2. 容易人为读取排错和被 Python 等外部脚本处理。
3. 项目文件的体量并不大，序列化耗时可忽略不计。

但是！对于体积巨大且为纯二进制内容的**波形图顶点数据**和**缩略图索引**，则存放在同级目录下一个隐藏的 `.cache` 扩展名里，使用极速的 `rmp-serde` (MessagePack) 二进制序列化，避免拖慢工程主 JSON 体积。
