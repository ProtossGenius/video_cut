# 项目文件格式

统一支持两种工程落盘形式：
1. **`.vcut` 格式**：具有严格 Schema 的 JSON 文本格式，记录完整的轨道、切片元数据及效果树。
2. **`.lua` 声明式工程脚本**：将项目完整表达为符合 Lua DSL 语法的可执行脚本。加载时通过 Lua 沙箱求值重构项目，支持跨平台脚本级版本管理与团队合并。

## 选择文本/脚本的理由
1. 对版本控制极为友好（可以配合 git 做项目的多人增量协作和 diff 追溯）。
2. 容易人为读取排错和被 Python/Lua 等外部脚本批量处理。
3. 项目文件的体量并不大，序列化耗时可忽略不计。

对于体积巨大且为纯二进制内容的**波形图顶点数据**和**缩略图索引**，则存放在同级目录下的 `.cache` 扩展名里，使用极速的 `rmp-serde` (MessagePack) 二进制序列化，避免拖慢工程主文件体积。
