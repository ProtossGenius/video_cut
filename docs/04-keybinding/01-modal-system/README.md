# 模态系统 (Modal System)

全局的状态机枚举，用来决定同一个按键在不同环境下触发什么行为。

## 状态定义
```rust
pub enum Mode {
    Normal,         // 默认编辑模式
    Visual,         // (v 小写) 范围选择模式
    VisualLine,     // (V 大写) 切片选择模式
    Command,        // (:) 命令行输入模式
    Insert,         // (i) 文本编辑器或标题输入模式
    Editor,         // 纯 Lua 代码编辑面板模式
    Search,         // (/) 项目或资源搜索模式
    Mark,           // (m) 正在等待输入锚点名称状态
    Goto,           // (') 正在等待跳转锚点按键状态
}
```

## Normal 模式内置核心键位
- `Space`: 播放 / 暂停
- `w` / `b`: 跳转到上/下一个有声音的地方（静音检测功能）
- `W` / `B`: 跳转到上/下一个设定的锚点
- `j` / `k`: 轨道内左右微调移动光标
- `J` / `K`: 跳转到当前轨道的上/下一个切片断点边界
- `s`: 切断当前轨道的切片 (Split)
- `q<字母>`: 开始录制键盘宏到指定寄存器（如 `qa` 录制到寄存器 a），录制期间再次按 `q` 结束录制。
- `@<字母>`: 回放指定寄存器的键盘宏（如 `@a`）。
- `@@`: 重复执行上一次执行过的键盘宏。
- `+`: 打开文件导入页面悬浮窗，只显示视频/图片格式。
