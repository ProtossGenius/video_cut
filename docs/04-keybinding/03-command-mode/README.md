# 命令模式 (Command Mode)

底部的交互命令行，按 `:` 即可呼出（兼容中文输入法下的 `：`）。

## 内置命令列表
- `:message`：开启悬浮的只读文本窗口，查看底层的历史错误和调试输出日志。
- `:history`：开启历史命令面板。可 `j/k` 选择某条过去的命令，按 `Enter` 填入命令行进入编辑，再按 `Enter` 即可重复执行。
- `:split`：切片分割命令（同快捷键 `s` 的底层映射）。
- `:Marks`：展示并编辑所有的锚点（时间点与描述文本）。
- `:editor <name>`：若带有切片名字，则进入该切片的特效脚本编辑界面。如果不带名字，默认打开光标当前聚焦的切片脚本。
- `:name <name>`：更改当前轨道的名称。
- `:merge`：在选中 (`visual`) 状态下，合并高亮的切片为一个物理引用块。
- `:mergecut`：基于高亮范围左右两刀切断，并将中间独立出来进行合并。

## 跳转命令 (`:goto`) 解析
支持灵活的时间格式：
- `goto 10`：跳转到距离光标最近的以 `10s` 结尾的绝对位置。
- `goto 10.12`：毫秒级跳转（10s 120ms）。
- `goto 1:10`：跳到最近的 x 小时 1分 10秒处。
- `+1:15.3` / `-10.0`：带有正负号代表相对于当前光标位置的增量移动。
