# 命令模式 (Command Mode)

底部的交互命令行，按 `:` 即可呼出（兼容中文输入法下的 `：`）。

## 内置命令列表
- `:help` / `:h`：呼出独立的**命令参考帮助弹窗**。按行整齐列出当前所有支持的命令名、别名、参数说明及功能描述。支持按斜线 `/` 开启实时搜索框进行关键字过滤匹配，使用 `j`/`k` 键上下移动高亮行，按 `Enter` 快速把命令填入命令行执行，按 `Esc` 关闭。
- `:message`：开启悬浮的只读文本窗口，查看底层的历史错误和调试输出日志。
- `:history`：开启交互式历史命令弹窗。支持按行浏览历史命令，支持 `/` 搜索过滤，按 `j`/`k` 选择命令，按 `Enter` 填入命令行直接复用编辑执行，按 `Esc` 关闭。
- `:split` / `:s`：切片分割命令（同快捷键 `s` 的底层映射）。
- `:Marks` / `:marks`：弹出交互式锚点管理弹窗，支持按行查看、内联编辑锚点描述、斜线搜索过滤与回车定位跳转。
- `:editor <name>` / `:e <name>`：若带有切片名字，则进入该切片的特效脚本编辑界面。如果不带名字，默认打开光标当前聚焦的切片脚本。
- `:name <name>`：更改当前轨道的名称。
- `:lock` / `:unlock`：锁定/解锁当前播放头聚焦的切片（防止涟漪效应移位）。
- `:speed <multiplier>`：设置当前聚焦切片的播放速度倍率（如 `:speed 2.0`）。
- `:merge`：在选中 (`visual` / `visual_line`) 状态下，合并高亮的切片为一个物理引用块。
- `:mergecut`：基于高亮范围左右两刀切断，并将中间独立出来进行合并。
- `:export_lua [path]` / `:save_lua [path]`：将当前完整剪辑项目导出为 Lua 项目脚本，可完全通过脚本重现全部轨道与切片。
- `:w` / `:write`：保存工程到文件（支持 `.vcut` 或 `.lua`）。
- `:q` / `:quit`：返回主导航页面。

## 跳转命令 (`:goto` 或直接时间码) 解析
支持灵活的时间格式（无需写 `goto` 前缀亦可直接解析）：
- `:goto 10` 或 `:10`：跳转到距离光标最近的以 `10s` 结尾的绝对位置。
- `:goto 10.12` 或 `:10.12`：毫秒级跳转（10s 120ms）。
- `:goto 1:10` 或 `:1:10`：跳到最近的 x 小时 1分 10秒处。
- `:+1:15.3` / `:-10.0`：带有正负号代表相对于当前光标位置的增量移动。
