# 多轨道合成器 (Compositor)

从帧缓存处拿到的可能是一个 `1080p` 大小的底层视频纹理，以及 `720p` 但叠加了旋转属性的素材 2，还有透明度只有 50% 的文字水印。

合成器会从底层垃圾轨道开始网上遍历所有带有激活属性的切片。
然后构建一个渲染树，从后向前（Back-to-Front Painter's Algorithm）或者依靠在 fragment shader 里的 Alpha 深度计算混合绘制，最终生成一张用于提交给 egui 展示的复合呈现用的 `TextureView`。
在需要导出的时候，这个最终绘制目标不是屏幕交换链，而是转移到后台去输出离屏渲染，复制给编码模块进行编码保存成 `.mp4`。
