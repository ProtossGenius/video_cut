# 多轨道合成器与极速导出管线 (Compositor & Smart Concat Export)

从帧缓存处拿到的可能是一个 `1080p` 大小的底层视频纹理，以及 `720p` 但叠加了旋转属性的素材 2，还有透明度只有 50% 的文字水印。

合成器会从底层开始向上遍历所有带有激活属性的切片。
然后构建一个渲染树，从后向前（Back-to-Front Painter's Algorithm）混合绘制，生成用于提交给 egui 展示的复合呈现用纹理。

## 剪切流程性能优化：分片预渲染与极速拼接 (Smart Chunk Pre-rendering & Fast Concat)

为了将最终长视频导出的耗时降低到秒级，系统内置了分片预渲染与智能拼接机制：
1. **静默分片预渲染 (Background Chunk Pre-rendering)**：
   - 监听时间线切片的修改时间戳。
   - 对超过 $N$ 分钟（默认 3 分钟）未发生改动的时间片段（Chunk），在后台空闲线程池中自动启动离屏渲染，预先生成 `.chunk` 无损编码片段。
2. **极速无重编码拼接导出 (Fast Concat Export)**：
   - 当用户触发最终导出时，系统检测已预渲染的分片与未预渲染/新修改的分片。
   - 仅对发生改动的新切片进行 GPU 合成与编码；已预渲染的分片直接复用。
   - 最终输出直接采用流级拷贝（Stream Copy / Fast Demux-Mux Concat）按时间戳顺序无缝拼接，使整片导出耗时从数十分钟缩减为数秒。

## 交互式导出控制与编码预设 (:export & Export Modal)
- **命令与快捷唤出**：支持 `:export [output_path] [h264|hevc|prores]` 或在菜单中点击“导出视频”。
- **多编码预设**：
  - `H.264 / MP4 (兼容性推荐)`: 快速硬件加速，广泛适用于网络与多平台分发。
  - `H.265 / HEVC (高压缩比)`: 在保持高画质的同时节省 40% 体积。
  - `Apple ProRes 422 (母带级)`: 适用于专业级调色与后续工程归档。
- **实时进度与 ETA 监控**：模态窗口展示当前已处理帧数、渲染百分比进度条、当前实时倍速（如 2.4x）以及剩余时间倒计时。
